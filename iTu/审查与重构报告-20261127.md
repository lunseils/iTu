- 项目：`iTu/`，命名空间 `iTu.*`，版本 `1.1.19`，`.NET 10 WinForms / net10.0-windows`

## 一、问题清单

按严重程度分级。「确认问题」为已定位且可直接复现或由代码路径必然触发；「潜在风险」为特定输入/时序下才显现，或修复需改变公共表面、按约束记录不改。

### S 级（数据损坏 / 功能全线不可用）——确认问题

| # | 文件与位置 | 根因 | 影响范围 | 修复 |
|---|---|---|---|---|
| S0 | `Core/ResultWriter.TrySave` | 11-23 的「JPEG 质量 92」改动把 `new EncoderParameters(1)` 套用到所有格式；PNG/BMP 时 `Param[0]` 为 null，GDI+ `Image.Save` 抛异常。而 `FileMode.Create` 已先建文件 → 残留 **0 字节、无 PNG 签名**的 `.png` | 默认格式即 PNG，保存链路全线报「这不是一个图像文件 (0xbad20009)」 | PNG/BMP 传 `null` 编码器参数；仅 JPEG 传 92 质量；catch 清理半成品并清空 `out path` |
| S1 | `Core/ResultWriter.TrySave` + `ImageUtil.EnsureUniquePath` | catch 无条件 `File.Delete(path)` 与 `File.Exists` 探测构成 **TOCTOU**：并发同秒保存时，A 的失败回滚会删掉 B 刚写好的文件 | 多会话/快速连拍下图片丢失，属本轮第一轮修复引入的回归 | 新增 `ImageUtil.CreateUniqueFile`，用 `FileMode.CreateNew` 原子抢占路径；`TrySave` 仅在 `owned`（本次确实创建）非空时删除 |
| S2 | `Ui/ShareService.SendByMail` | 秒级文件名同秒覆盖；`image.Save(string)` 失败留 0 字节 PNG；`_ = new Timer` 无强引用可被 GC 提前回收；`mailto:` subject 中文未编码 | 邮件分享偶发附件损坏、定时器失效、部分客户端主题乱码 | GUID 唯一名 + `FileMode.CreateNew` + catch 删除半成品 + 静态 `HashSet<Timer>` + lock 持有并在回调后 Remove/Dispose + `Uri.EscapeDataString` |
| S3 | `Core/ScreenRecorder.Stop` | ffmpeg 超时被 `Kill()` 后，仅凭输出 `size > 0` 判成功 | 留下缺 moov/trailer 的**不可播放**视频 | `killed` 标志并入失败条件，并 `DeleteOutputFile()` |
| S4 | `Core/AppSettings.Save` | `WriteAllText` 非原子覆盖，中途失败留下截断 json | 下次启动配置全丢/反序列化异常 | 写 `.tmp` 后 `File.Move(tmp, FilePath, true)` 原子替换 |
| S5 | `Core/AppSettings.Load` | 对 `settings.json` 中显式 `null` 的字符串不归一 | `SaveDirectory` / `TranslateTarget` / 热键链路空引用 | 新增 `Normalize()`，`Load` 返回前对 string 属性 `??=` 默认值 |

## 二、重构方案

**原则**：不改变公共接口契约、返回结构与调用方行为；以「职责归位」替代「大改架构」。

1. **保存职责收敛**：`Core/AnnotationHistory.cs` 中与图像落盘/工具方法混杂的静态 helper 拆出为独立 `Core/ImageUtil.cs`。`AnnotationHistory` 回归单一职责——只维护撤销栈。
2. **唯一写入口**：所有落盘统一经 `ResultWriter.TrySave`；`ImageUtil` 只提供 `BuildFileName` / `EnsureUniquePath` / `CreateUniqueFile` / `EnsureDirectory` / `HasTransparency` / `SelectCodec` / `CopyToClipboard` 等无副作用或单一副作用的原语，不再保留第二套 `Save` 实现。
3. **分层窗口单图层**：`OverlayForm` 作为唯一 `WS_EX_LAYERED` 窗口覆盖整个虚拟桌面；遮罩、选区、圆角条、扩拉线、主/次级胶囊、颜色弹层、标注、放大镜、提示全部绘入同一张 32bppPArgb surface。`ToolFlyout` / `ColorPickerChrome` 由 `Form` 降级为纯绘制对象，通过 `Changed` 事件驱动脏区重绘。
4. **脏区渲染**：`LayeredSurface.SurfaceBuffer.Present()` 复用 DIB / MemoryDC；`Render(Rectangle? dirtyScreen)` 以屏幕绝对坐标计算脏区，`Redraw()` 先保存旧 flyout/picker/hint 区域再合并新区域，避免残影。
5. **坐标体系统一**：`PixelOrigin` / `PixelSize` 作为虚拟桌面 ↔ 局部 surface 的唯一换算入口，修正放大镜与采样两处漏换算。

改动规模：`12 files changed, 148 insertions(+), 250 deletions(-)`，新增 `Core/ImageUtil.cs` 与验证工程 `pngprobe/`。

## 三、逻辑优化点

| 优化 | 机制 | 收益 |
|---|---|---|
| 路径原子抢占 | `FileMode.CreateNew` 生成唯一文件名，返回 `actual` 真实路径与 `owned` 归属标记 | 消除并发保存互删（TOCTOU）；回滚只删自己创建的文件 |
| 配置原子写 | `.tmp` + `File.Move(..., true)` | 消除截断 json 导致配置全丢 |
| 编码器参数按格式分发 | JPEG → `EncoderParameters(Quality=92)`；PNG/BMP → `null` | 消除 0 字节 PNG（S0 根因） |
| 透明检测精度 | 按实际 `PixelFormat` 锁位、步长 4、补扫边缘行列 | 圆角/羽化图不再误判为不透明 |
| 模糊计算 | `colBuf` 副本参与垂直卷积 | 消除滑动窗口自污染导致的条带 |
| ffmpeg 结果判定 | `killed` 并入失败条件 + 删除半成品 | 不再产出缺 trailer 的坏视频 |
| Timer 生命周期 | 静态 `HashSet<Timer>` + lock 强持有，回调后 Remove/Dispose | 避免 GC 提前回收导致回调不执行 |
| 等待上界 | `Math.Min(wait, int.MaxValue)` | 消除 long→int 溢出后的忙等 |
| 渲染脏区 | 合并新旧弹层区域一次性重绘 | 消除手绘控件状态变化时的残影 / 刮刮奖式显现 |

### 建议的复核场景（未在本轮执行，供后续按需定向验证）

1. **S0 复现**：默认 PNG 格式截图并保存 → 产物应为非空且可打开，不再报 `0xbad20009`。
2. **S1 边界**：同一秒内连续触发两次及以上保存；或人为让第二次写入抛异常 → 确认第一次产物不被回滚删除。
3. **S2 异常路径**：邮件临时目录设为不可写 → 确认无残留 0 字节 PNG 且不影响主流程；中文主题在目标邮件客户端不乱码。
4. **S3 边界**：ffmpeg 录制中强制超时/进程被杀 → 确认不留下不可播放的输出文件。
5. **S4/S5 异常路径**：`settings.json` 手工写入显式 `null`、截断内容 → 确认配置归一到默认值且不被覆写为坏文件。
6. **M1/M2 多屏**：主屏在右、副屏在左（负坐标）时拖动选区 → 放大镜位置、采样内容、脏区刷新正确。
7. **M4 边界**：1×1、2×2 极小图，仅圆角/羽化边缘 1px 含 alpha 的图 → 透明判定正确、强制 PNG。
8. **回归检查（最小集）**：仅覆盖本轮改动涉及的保存、邮件分享、录制停止、设置读写、放大镜、模糊标注、颜色弹层，不扩测旧功能。
