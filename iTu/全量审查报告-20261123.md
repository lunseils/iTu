## 四、低危与优化建议（摘要）

- **低危已修**：`BuildFileName` null 防护、`StartupHint` null 兜底、manifest 版本/命名、README 过时数据、HotkeyManager 异常可见性（详见中危表）。
- **低危记录**：`ImageRounder` 释放入参的 API 契约、`_ratioCache` 静态字典无界、`DisplayInfo` 回调未显式 StdCall、`Toast` 未布局即取宽、`RoundedButton.OnMouseUp` 未判按键、`Glyphs`/`MenuTexture.Tile()` 缓存细节、多处一次性 Font/ToolTip 未释放、`ocr.ps1` 的 `exit 3` 无专属文案。
- **优化建议（未实施）**：放大镜 `SetPixel` 改 `LockBits` 直写、`ForceOpaque` 改 unsafe 指针/SIMD、ffmpeg 路径缓存、`_frames` 改 Queue 降低头删开销、设置页背景改尺寸无关纹理。以上均属性能优化，不影响正确性。

## 五、发布部署清单

### 5.1 依赖列表

| 依赖项 | 必需性 | 说明 |
|---|---|---|
| .NET 10 Desktop Runtime | 轻量版必需 / 独立版内置 | `Microsoft.NETCore.App` + `Microsoft.WindowsDesktop.App` 10.0；独立版已打包 |
| Windows PowerShell 5.1 | 本地 OCR 必需 | Win10/11 自带；WinRT 类型投影语法仅 5.1 支持 |
| WinRT OCR + 「光学字符识别」语言包 | 本地 OCR 必需（在线 OCR 可绕过） | 优先 `zh-Hans`；缺包 `ocr.ps1` exit 2 → 界面友好提示 |
| ffmpeg.exe（PATH） | 仅 MP4 录制可选 | 无则自动降级内置 GIF，面板明示后端 |
| SiliconFlow API Key + 网络 | 仅在线 OCR/翻译可选 | 域名白名单仅 `api.siliconflow.cn/.com` HTTPS |
| VC++ 运行库 | 无需单独安装 | 独立版内置运行时；未引入需额外 Redist 的原生库 |
| Pillow（Python） | 仅构建期（重生成图标） | 非运行时依赖 |

### 5.2 推荐运行环境
- **独立版（推荐分发）**：Windows 10 1809+ / 11，x64，双击即用，无需预装 .NET。
- **轻量版**：需先装 .NET 10 Desktop Runtime。
- DPI：PerMonitorV2，支持混合 DPI 多显示器。

### 5.3 启动命令
- 正常：双击 `iTu.exe`（常驻托盘 + 气泡提示热键）
- 仅开设置：`iTu.exe --settings`
- 二次双击已运行实例：通过 `WM_ACTIVATE_APP` 唤起截图
- 发布：`publish.cmd` / `--no-pause` / `--force`

### 5.4 打包注意事项
1. 发布前退出运行中的 iTu，否则 exe 被占用（`--force` 自动 taskkill）。
2. `publish.cmd` 必须保持 **GBK+CRLF**（本轮已修复并由 `.gitattributes` 锁定）。
3. `ocr.ps1` 必须保持**纯 ASCII 无 BOM**；已作为 `EmbeddedResource`（逻辑名 `iTu.OcrScript`）嵌入 exe。
4. 发布后核对：独立版 ≈ 47 MB、轻量版 ≈ 513 KB；两目录各只有单个 `iTu.exe`。

### 5.5 已知平台限制
- 仅 x64（无 x86/ARM64 产物）
- 本地 OCR 依赖系统语言包；MP4 依赖外部 ffmpeg
- 企业环境 `powershell -EncodedCommand` 可能被 EDR 拦截（需白名单）
- 全局热键被占用时注册失败，托盘/关于页会标注
